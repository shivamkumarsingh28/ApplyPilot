## Bugs fixed

1. **CI would fail on lint** — `backend/app/api/routes/pdf_tools.py` had unsorted
   imports (ruff `I001`). Fixed with `ruff check --fix`; re-verified clean and the
   affected backend tests (19) still pass.
2. **CI never ran** — `.github/workflows/ci.yml` only triggered on pushes to
   `main`, but this repository's branch is `development`. Added `development`
   to the push branches so backend, bot, frontend and extension CI actually run.

## Additions

- `.dockerignore` at repo root and in `backend/`, `frontend/`, `bot/` — build
  contexts no longer include `.venv`, `node_modules`, `.next`, caches or `.env`,
  so images build faster and local secrets cannot leak into an image context.
- `.gitignore`: added `.venv-*/`, `.ruff_cache/`, `*.tsbuildinfo` so the removed
  junk cannot be re-committed.
- This report.

## Deliberately NOT changed

- **Comments**: the codebase already has clear module docstrings and comments
  explaining non-obvious logic. Commenting every line was intentionally not done —
  it lowers readability and is not production practice.
- **`.env`** (local, untracked): contains real secrets and stays out of git.
  Judges should copy `.env.example` / run `make setup`.
- Files outside the repo (`E:\Meta AI Hackathon\learn meta model\`, pitch
  scripts) were left untouched by the owner's decision.
- Docker stack was left running after the smoke test; stop with
  `docker compose --profile bot down`.

python scripts/setup_env.py        # or: cp .env.example .env
