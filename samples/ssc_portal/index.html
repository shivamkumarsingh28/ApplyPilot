How to test ApplyPilot on this page

  1. Start backend (:8000) + website (:3000). Fill your Profile (name, father/mother, DOB, category, mobile, email, address, city, state, PIN, qualification, marks).
  2. Upload to your Vault: photo, signature, 10th & 12th marksheets, degree, caste certificate, domicile, ID proof, birth certificate (use the matching "Type" for each).
  3. Load the extension (chrome://extensions → Developer mode → Load unpacked → extension/), sign in, open this page, click Scan this page.
  4. Review matched fields → Fill selected fields. Blue = filled, yellow = please check. Captcha, password, declaration and ID numbers must stay empty/unticked.
  5. For uploads: pick the vault match the extension suggests, or download the vault file and select it manually in Part-V.

Serving tip: run python -m http.server 5500 inside samples/ssc_portal/ and open http://localhost:5500/ (extension works best on http pages, not file://).
